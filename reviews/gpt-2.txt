That’s the single biggest remaining credibility gap.

### What to build (minimum viable)

* Add a new CLI command: `riemann-solver zeta-zeros`
* Start with **Odlyzko tables** (fastest, most reproducible)

  * You already have `FUTURE_ODLYZKO_DATABASE.md` sitting there, so clearly you know this is coming. ([GitHub][1])

  * Map heights (\gamma_n) → unfolded levels using the Riemann–von Mangoldt counting function (N(T))

* And it produces:

  * spacing histogram
  * variance
  * KS distance vs Wigner surmise (or exact GUE spacing)

**Why this is #1:** It’s the bridge between “toy systems” and “actual RH-adjacent evidence.”
